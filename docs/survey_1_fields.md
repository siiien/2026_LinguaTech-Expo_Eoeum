# 설문 1 · 구글폼 열과 DB 필드 대응표

설문 1(인물 프로필) 구글폼 응답 CSV를 `research.db`에 저장할 때 쓰는 대응표입니다.
저장 코드는 `scripts/import_survey_1.py`이며, 이 표와 코드의 `ITEMS`는 항상 같은 내용이어야 합니다.

## 저장 위치

| CSV | DB 테이블 | 한 행에 담는 것 |
| --- | --- | --- |
| `참가자 ID를 입력해주세요.` 열 | `participant` | 참가자 1명 |
| 문항 32개의 열 이름·문구 | `survey_item` | 설문 1의 응답 칸 1개 (참가자 수와 관계없이 한 번만 등록) |
| 참가자 1명의 각 문항 답변 | `survey_answer` | 참가자 1명의 문항 답변 1개 |

CSV는 **참가자 1명 = 1행(가로)**이고, `survey_answer`는 **답변 1개 = 1행(세로)**입니다. 스크립트가 가로 행을 세로로 펼쳐 저장합니다.
참가자 1명당 `survey_answer` 32행, 3명이면 96행입니다.

## `prompt_text`에 넣는 내용

참가자가 구글폼에서 실제로 읽은 문구를 넣습니다. 답변만 남아 무엇에 대한 답인지 잃어버리지 않기 위해서입니다.

| 문항 | `prompt_text` |
| --- | --- |
| D1, D2 | 질문 제목 + 질문 설명(있는 경우). 객관식은 선택지도 함께 |
| D3 | `상황 번호 · 상황 제목` + 상황 전문 + 빈 줄 + 질문 제목. 예: `상황 03 · 팀 과제 상금` / 상황 전문 / `03. 가장 중요한 이유` |
| D4 01~06 | 받은 메시지 문구. 04는 질문 설명 "당신은 내일 저녁에 이미 일정이 있습니다."도 함께 |
| D4 07 | 질문 제목 + 선택지(반말 / 존댓말 / 섞어 씀) |

D3 상황 전문은 스크립트의 `D3_SCENARIOS`에 있습니다. 구글폼의 상황 문구를 고치면 여기도 함께 고칩니다.

## 저장 규칙

- **열 이름 확인**: CSV 열 이름이 위 표와 하나라도 다르면 아무것도 저장하지 않고 멈춥니다. 비교할 때 둥근 따옴표(“ ”)와 곧은 따옴표("), 연속 공백은 같은 것으로 봅니다.
- **참가자 ID**: 공백을 지우고 대문자로 바꿉니다(` p01 ` → `P01`). `P01` 형식이 아니면 멈춥니다.
- **중복 제출**: 같은 참가자가 두 번 이상 제출했으면 타임스탬프가 가장 늦은 응답만 저장합니다.
- **답변 정제**: 답변 안의 줄바꿈은 그대로 보존합니다(D4 답장의 끊어 보내기 분석에 필요). 각 줄 끝의 공백과 답변 전체의 앞뒤 공백만 지웁니다.
- **빈칸**: 빈 답변은 `NULL`로 한 행을 저장합니다. 필수 문항이 비어 있으면 멈춥니다.
- **다시 실행**: 여러 번 실행해도 행이 늘어나지 않습니다. 같은 참가자·문항은 새 답변으로 덮어씁니다.
- **한 번에 저장**: 저장 중 하나라도 오류가 나면 그 실행에서 넣은 내용은 모두 취소됩니다.

## 실행 방법

레포 최상위 폴더에서 실행합니다. 추가 설치는 필요 없습니다.

```
# 1) DB에 쓰지 않고 CSV만 검사
python scripts/import_survey_1.py --csv data/survey_1.csv --dry-run

# 2) DB 복사본에 먼저 저장
python scripts/import_survey_1.py --csv data/survey_1.csv --db data/research_test.db

# 3) 실제 DB에 저장
python scripts/import_survey_1.py --csv data/survey_1.csv --db data/research.db
```

DB 파일이 없으면 경로 오타로 빈 DB가 생기지 않도록 멈춥니다. 새 DB를 만들 때만 `--create-db`를 붙입니다.
테이블이 없으면 새로 만들고, 이미 있으면 필요한 컬럼이 있는지만 확인합니다.

## 저장 후 기대값

| 확인 | 기대값 |
| --- | --- |
| `survey_item` (설문 1 문항) | 32행 |
| `survey_answer` | 참가자별 32행, 3명이면 96행 |
| 필수 문항 빈칸 | 0개 |

실제 응답 CSV와 `research.db`는 개인 정보가 들어 있으므로 깃에 올리지 않습니다.
